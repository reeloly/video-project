# For Product Demos
Structure the prompt with these components:

**15-30 seconds:**
1. Product Shot (3-5s) - Hero shot of product
2. Feature Demo 1 (8-10s) - Show main feature
3. Feature Demo 2 (8-10s) - Show secondary feature
4. CTA (3-5s) - Purchase prompt

**30-60 seconds:**
1. Product Shot (5-8s) - Hero shot of product
2. Feature Demo 1 (10-12s) - Show main feature
3. Feature Demo 2 (10-12s) - Show secondary feature
4. Feature Demo 3 (10-12s) - Show third feature
5. Results (5-8s) - Show end result
6. CTA (5s) - Purchase prompt

**60-90 seconds:**
1. Product Shot (8-10s) - Hero shot from multiple angles
2. Feature Demo 1 (15-18s) - Detailed main feature
3. Feature Demo 2 (15-18s) - Detailed secondary feature
4. Feature Demo 3 (12-15s) - Show third feature
5. Results (10-12s) - Show impressive end result
6. CTA (5-8s) - Purchase prompt with offer
