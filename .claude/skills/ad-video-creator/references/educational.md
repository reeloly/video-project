# For Educational/How-To
Structure the prompt with these components:

**15-30 seconds:**
1. Problem/Question (3-5s) - State the issue
2. Step 1 (8-10s) - First solution step
3. Step 2 (8-10s) - Second step
4. Product as Solution (5-8s) - How product helps
5. CTA (3-5s) - Learn more

**30-60 seconds:**
1. Problem/Question (5-8s) - State the issue clearly
2. Step 1 (10-12s) - First solution step explained
3. Step 2 (10-12s) - Second step demonstrated
4. Step 3 (10-12s) - Third step shown
5. Product as Solution (8-10s) - How product makes it easier
6. CTA (5s) - Try it/Learn more

**60-90 seconds:**
1. Problem/Question (8-12s) - Detailed problem explanation
2. Why It Matters (8-10s) - Context and importance
3. Step 1 (12-15s) - First solution step with details
4. Step 2 (12-15s) - Second step with examples
5. Step 3 (12-15s) - Third step demonstrated
6. Product as Solution (10-12s) - How product simplifies everything
7. CTA (5-8s) - Try it/Learn more
