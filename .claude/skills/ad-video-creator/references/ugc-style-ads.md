# For UGC-Style Ads
Structure the prompt with these components:

**15-30 seconds:**
1. Personal Hook (3-5s) - "Just got this..." authentic opener
2. Unboxing/Discovery (8-12s) - Real reaction to product
3. Quick Use (8-10s) - Show it working casually
4. Recommendation (3-5s) - "You need this!"

**30-60 seconds:**
1. Personal Hook (5-8s) - "Just got this..." authentic opener
2. Unboxing/Discovery (10-15s) - Real reaction, show packaging
3. First Impression (8-12s) - Initial thoughts
4. Real-life Use (12-15s) - Show it in everyday setting
5. Personal Recommendation (5-8s) - Genuine endorsement

**60-90 seconds:**
1. Personal Hook (8-10s) - Story-based opener
2. Unboxing/Discovery (15-20s) - Detailed unboxing, packaging
3. First Impression (10-15s) - Initial thoughts and reactions
4. Real-life Use (20-25s) - Multiple use cases
5. Before/After (8-12s) - Show the difference
6. Personal Recommendation (8-10s) - Genuine detailed endorsement
