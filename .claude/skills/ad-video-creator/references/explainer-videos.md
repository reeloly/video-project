# For Explainer Videos
Structure the prompt with these components (adjust timing based on total length):

**15-30 seconds:**
1. Problem Statement (5-8s) - Show the pain point
2. Solution Introduction (5-8s) - Introduce your product
3. How It Works (8-10s) - Quick feature highlight
4. CTA (3-5s) - Clear next step

**30-60 seconds:**
1. Problem Statement (8-12s) - Show the pain point
2. Solution Introduction (8-12s) - Introduce your product
3. How It Works (15-20s) - Show key features
4. Benefits (8-12s) - What users gain
5. CTA (5s) - Clear next step

**60-90 seconds:**
1. Problem Statement (12-15s) - Show the pain point in detail
2. Solution Introduction (10-15s) - Introduce your product
3. How It Works (25-35s) - Demonstrate multiple features
4. Benefits (10-15s) - What users gain
5. CTA (5-8s) - Clear next step
